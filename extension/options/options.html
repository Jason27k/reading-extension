Read Along

Read Along needs access to websites to read them and to reach Google's TTS service.

Stored only in this browser. Restrict the key to the Cloud Text-to-Speech API.

Only Standard and WaveNet voices are listed, since they support word highlighting.

Image descriptions (alt text) are always skipped.

Usage this month

—

Characters billed by Google, added up across your synced devices. Check your plan's free tier in the Cloud console.

Keyboard shortcuts

Alt+Shift+PPlay / pause (starts from the selection if there is one)
Alt+Shift+RRead from the selection
Alt+Shift+SStop
Alt+Shift+. / ,Faster / slower
Alt+Shift+→ / ←Next / previous sentence
Alt+Shift+↓ / ↑Next / previous paragraph
Alt+Shift+BShow / hide the control bar

Change them at about:addons → gear icon → Manage Extension Shortcuts.
